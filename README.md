# End-to-End Data Analytics Project

## 📌 Overview

This project demonstrates an **end-to-end data analytics workflow**—from raw data extraction to strategic business presentation. The goal is to ingest raw data, perform exploratory data analysis (EDA) and data cleaning using Python, query clean datasets using MySQL, build an interactive Power BI dashboard, write an analytical report, and generate an executive presentation using Gamma AI.

## 📁 Dataset

* **Source:** customer_shopping_behavior.csv
* **Format:** CSV
* **Description:** Contains transactional/operational records including attributes like dates, customer demographics, sales figures, categories, and financial metrics.

## 🛠️ Tools & Technologies

* **Data Processing & EDA:** Python (`pandas`, `numpy`, `matplotlib`, `seaborn`)
* **Database & Querying:** MySQL Workbench
* **Data Visualization:** Power BI Desktop
* **Reporting & Presentation:** Gamma App (AI Presentation Tool) & PDF/Markdown Documentation

## 🚀 Project Steps & Methodology

### 1. Data Ingestion & EDA (Python)
* Loaded raw dataset into Python using `pandas`.
* Analyzed missing values, duplicate entries, data types, and statistical summaries.
* Conducted initial data visualizations to uncover distributions and outliers.

### 2. Data Cleaning & Transformation
* Handled missing and duplicate records.
* Standardized column headers, datetime values, and categorical data types.
* Exported the cleaned dataset into structured format (`cleaned_data.csv`) for database ingestion.

### 3. Database Management & SQL Analysis (MySQL)
* Created relational tables and schema in MySQL.
* Imported cleaned dataset into MySQL database.
* Executed complex SQL queries (Aggregations, Window Functions, JOINs, Groupings) to answer core business questions.

### 4. Interactive Dashboard Creation (Power BI)
* Connected Power BI to MySQL / Cleaned CSV data source.
* Modeled data schema and created DAX measures for KPIs.
* Built interactive visual pages highlighting key drivers, trends, and breakdown analytics.

### 5. Final Report & Presentation (Gamma AI)
* Compiled business findings into a structured summary report.
* Created an executive presentation using Gamma AI to present key takeaways and recommendations clearly to non-technical stakeholders.
